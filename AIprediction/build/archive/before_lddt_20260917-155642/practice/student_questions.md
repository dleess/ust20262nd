# 학생용 확장 문제: 입력을 바꾸면 무엇을 확인해야 할까?

정규 수업에서는 각 개념 설명 직후 6쪽 활동지의 해당 문항을 풉니다. 아래는 수업 후에 따로 풀 수 있는 30분 확장 문제이며, 강의 끝에 몰아서 수행하는 필수 실습이 아닙니다.

이 실습의 A3M·상동서열 라벨·결과 숫자는 모두 **허구 학습 자료**입니다. A3M은 12열 문법 예시, JSON은 별도의 가상 180잔기 표적 사고 실험입니다. 실제 예측을 실행하지 않습니다.

## 1. A3M 읽기 — 8분

1. `fictional_learning.a3m`은 query 포함 몇 행인가? query를 제외하면 몇 행인가? 정렬 열 수는 얼마인가?
2. `example_A2`의 `ACDeeEFGHIKLMN`에서 원문 글자 수와 정렬 열 수가 다른 이유를 설명하고, 소문자를 제외한 정렬 문자열을 쓰자. `ee`는 어느 query 정렬 열 직전에 있는가?
3. `example_A3`의 `-`와 `example_B1`의 `X`는 같은 뜻인가? 각 문자의 정렬 열 번호와 의미를 쓰자.

## 2. 입력 조작 — 12분

4. `python3 msa_lab.py --depth 4 --seed 7 --out runs/student01`을 실행한다. `report.json`에서 추출된 ID를 적고, query가 첫 행에 남았는지 확인한다. 같은 설정에서 새 출력 폴더를 쓰면 같은 행을 얻는가? 이 4행은 4개의 독립 진화 정보라는 뜻인가?
5. `group_A.a3m`과 `group_B.a3m`은 각각 몇 행인가? 무엇을 기준으로 나눴는가? A를 닫힌 상태, B를 열린 상태라고 부를 수 있는가?
6. `masked.a3m`에서 `example_A2`의 원문 문자열을 쓰자. query, `ee`, `example_A3`의 gap 중 무엇이 바뀌었는가? `--mask-columns 5,7,10`은 원문 문자열의 글자 위치인가, query 정렬 열인가?
7. 학생이 `ACDeeEFGHIKLMN`을 먼저 전부 대문자로 바꾸고 5번째 글자를 `X`로 바꿨다. 무엇이 잘못되는가? query까지 마스킹하면 어떤 비교 조건이 달라지는가?

## 3. 가상 결과 해석 — 10분

`synthetic_comparison.json`의 숫자는 사람이 만든 예시다. 거리 단위는 Å, pLDDT는 0–100이다. PAE는 두 가상 구간 사이의 요약값이며 전체 행렬이 아니다.

8. 거리와 신뢰도를 함께 보면 F1/F2/A1과 S1/B1/M1은 각각 어떤 후보 묶음으로 정리할 수 있는가? S2/M2를 “가장 크게 열린 새 상태”라고 바로 결론내리기 어려운 이유는 무엇인가?
9. F2의 평균 pLDDT가 가장 높다. F2만 남겨야 하는가? 나머지 후보를 확인하려면 어떤 구조 관측량·국소 신뢰도·독립 근거가 필요한가? 예를 하나씩 적자.
10. 8개 중 3개가 비슷한 거리의 후보라면 그 상태의 평형 점유율이 3/8인가? 왜인가? “masking이 더 좋은 예측법이다”라는 결론을 내릴 수 있는가?
11. 실제 비교 실험에서 MSA 조작 외에 고정하거나 기록해야 할 항목을 세 가지 이상 쓰자. 여기에 실제 단백질 구조가 존재한다는 결론을 내리기 위해 추가로 필요한 근거 한 가지를 쓰자.

컴퓨터 없이 진행할 때: 4번은 강사가 제공한 실행 보고서의 ID를 읽고, 6번은 각 행에서 소문자를 건너뛰며 손으로 처리한다.
