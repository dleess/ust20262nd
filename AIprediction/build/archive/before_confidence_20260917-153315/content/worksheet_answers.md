# 학생 활동지 해설 · 교사용

작성: Donghan Lee

진행: 관련 설명 직후 해당 쪽을 풉니다. 4쪽은 depth·clustering·masking 설명 사이에 한 문항씩 나누어 사용합니다. 모든 실습을 강의 끝까지 미루지 않습니다.

## 1쪽 · 종분화와 유전자 중복

1. H_A–M_A는 ortholog입니다. 두 유전자의 가장 최근 공통조상에서 종분화가 일어났습니다. H_A–H_B와 H_A–M_B는 paralog입니다. 두 경우의 유전자 분기는 중복 사건에서 시작합니다. 서로 다른 종의 유전자도 paralog일 수 있습니다.
2. H1–H2는 paralog, H1–M과 H2–M은 각각 ortholog입니다. M을 기준으로 H1·H2는 co-ortholog 관계입니다. 종분화 후 중복이 생겼기 때문입니다. 관계는 비교하는 유전자 쌍에 대해 정의합니다.
3. 유전자 계통수와 종 계통수, 중복·종분화·소실 사건에 대한 근거가 필요합니다. 높은 identity나 서로 다른 종이라는 정보만으로 orthology를 확정하지 않습니다.

## 2쪽 · A3M 읽기

1. Query 포함 7행, homolog 6행, 정렬 열 12개입니다. 중복 query와 동일한 homolog가 있어도 원시 행 수에는 포함되지만 독립 정보가 늘었다고 볼 수는 없습니다.
2. `ee`는 query 정렬 4열 직전의 insertion입니다. `ACDeeEFGHIKLMN`의 원문 길이는 14지만 정렬 열은 12개입니다. 대문자화하면 insertion을 match column으로 오해합니다.
3. A3의 5열은 gap이고 B1의 11열은 X입니다. Gap은 해당 정렬 위치에 잔기가 없는 대응, X는 잔기의 정체를 모르는 표식입니다. 실습에서는 알고 있는 homolog 잔기를 X로 가리는 경우도 있습니다.
4. 단순 복제는 독립 진화 정보를 늘리지 않습니다. Coverage·다양성·중복도와, 정의를 기록한 Neff를 함께 봅니다.

## 3쪽 · Coevolution과 ortholog/paralog

이 표는 계산을 위한 가상 자료입니다. A/B 중복이 H·M·R·F의 종분화보다 앞섰다는 유전자 이력을 문제에서 주었습니다. 실제 서열을 보고 이 이력을 추정한 결과가 아닙니다.

1. 합친 8행에서 `P(D_i) = 4/8 = 1/2`, `P(K_j) = 4/8 = 1/2`, `P(D_i, K_j) = 4/8 = 1/2`입니다. 독립이라면 공동 빈도는 `(1/2) × (1/2) = 1/4`여야 합니다. 두 열에 통계적 연관이 있습니다. 대조 자료는 `DD`, `DK`, `KD`, `KK`가 각각 2행이므로 각 열의 D/K 빈도는 같은 1/2이지만, `P(D_i, K_j) = 2/8 = 1/4`입니다. 다른 세 조합도 모두 1/4입니다. 한 열씩 보는 보존도·빈도가 같아도 두 열의 공동 분포는 달라질 수 있습니다. 이 빈도 계산만으로 진화 과정에서 두 위치가 서로 영향을 주었다고 입증한 것은 아닙니다.
2. A_H–A_M은 ortholog, A_H–B_M은 paralog입니다. A 내부에는 `DK`만 있고 B 내부에는 `KD`만 있습니다. 따라서 각 하위군 안에는 두 위치 모두 변이가 없어 그 안의 공변이를 평가할 정보가 없습니다. 합친 표의 패턴은 하위군 구분과 완전히 겹칩니다. A/B에서 서로 다른 조합을 조상으로부터 물려받은 경우에도 같은 표를 얻을 수 있습니다.
3. 8개 서열 행은 8회의 독립적인 진화 사건이 아닙니다. 여러 후손이 조상에게서 같은 잔기 조합을 물려받았을 수 있습니다. 조상 상태와 변화가 일어난 가지를 재구성하지 않고 변화 횟수·방향·보상 순서를 정할 수 없습니다. 잔기들이 직접 접촉한다는 결론도 내릴 수 없습니다. 간접적인 결합, 다른 기능적 제약, 계통·하위군 효과가 통계적 연관을 만들 수 있습니다. D/K의 전하가 반대라는 사실만으로 salt bridge를 단정하지 않습니다.
4. Ortholog들 역시 공통 조상을 공유하므로 계통적 비독립성이 남습니다. 가까운 종을 많이 모은 것과 여러 독립 가지에서 변이가 반복된 것은 다릅니다. 필요한 근거의 예: 종 계통수와 중복·소실을 고려한 유전자 이력, 정확한 정렬과 충분한 변이·계통 다양성, 하위군별 분석, 독립 가지의 변화 여부, 간접 연관을 고려하는 결합 분석, 접촉을 확인할 구조·실험 자료. 행 수나 Neff만 늘리는 것으로 모든 교란이 사라지지는 않습니다. 공진화 분석에 paralog를 무조건 제외하는 규칙을 적용하기보다 분석 목표와 도메인·기능·계통 구성을 확인합니다.

교사용 핵심 문장: **Ortholog/paralog는 유전자들이 어떤 사건으로 갈라졌는지를 설명하고, coevolution은 위치·분자 사이 진화적 제약의 연결을 묻습니다. MSA에서 보이는 공변이는 그 연결을 탐색하는 관측 신호이며, 진화 이력을 함께 보아야 합니다.**

## 4쪽 · 입력 조작과 대조 조건

1. 첫 행은 원래 query입니다. Query를 바꾸면 예측하려는 단백질 자체가 달라집니다. 같은 단백질에서 MSA 배경만 바꾸려는 비교에서 query를 고정합니다.
2. Group A/B는 가상 header의 사전 라벨로 나눈 것입니다. 3쪽의 A/B에는 진화 이력이 문제 조건으로 주어졌지만, 2·4쪽 A3M의 A/B는 이와 별개인 임의 라벨입니다. 이 라벨만으로 orthology·paralogy를 판단할 수 없습니다. AF-Cluster는 실제 서열의 유사성을 바탕으로 clustering합니다. 라벨 A/B가 열린 상태/닫힌 상태를 뜻하지 않습니다.
3. A2의 결과는 `ACDeeEXGXIKXMN`입니다. 소문자 `ee`는 보존하고, query 전체와 기존 gap도 보존합니다. 5·7·10은 원문 문자열의 문자 위치가 아닌 query 정렬 열입니다.
4. 예: 모델·가중치 버전, query 경계, template 유무, ligand/복합체 조성, 예측 seed, 표본 추출 seed, recycle 조건, 생성 모델 수, MSA 검색 DB·날짜. 모든 설정을 동시에 바꾸면 결과 변화의 원인을 분리하기 어렵습니다.

## 5쪽 · 가상 결과 해석

1. F1/F2/A1은 거리가 약 8 Å인 후보, S1/B1/M1은 약 16 Å인 후보 묶음으로 우선 정리할 수 있습니다. 하나의 거리만으로 구조 상태를 확정할 수는 없습니다. S2/M2는 낮은 평균 pLDDT와 높은 구간 간 PAE 때문에 불확실한 모델일 가능성을 먼저 확인합니다. PAE는 실제 측정 오차가 아닌 모델의 예측값입니다.
2. 최고 평균 pLDDT 하나만 선택하면 다른 구조 후보를 버릴 수 있습니다. 국소 confidence, 전체 PAE, 도메인 배치, 접촉, 물리적 충돌, 다른 seed의 재현성과 독립 실험 근거를 확인합니다.
3. 3/8은 이 가상 생성물 집합에서의 비율입니다. 평형 점유율이라고 해석할 근거가 없습니다. 입력 선택과 모델 샘플링 분포가 물리적 평형분포에 대응하는지 별도 검증해야 합니다. 실험 구조, NMR/FRET/SAXS 등의 제약 또는 검증된 물리적 모델과 비교할 수 있습니다.

숫자·짧은 서열은 모두 가상 학습 자료입니다. 실제 inference 또는 실험 결과로 인용하지 않습니다.
